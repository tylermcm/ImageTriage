# Codebase audit and triage, 2026-11-11

Whole-repository read of the QML-only application at `d7b7a84`. This file is the triaged list of
failures, shortsights and feature gaps, and records which were fixed in the pass that followed.

## How it was done and how far to trust it

- Five subsystem reads (data and file operations; the QML shell's Python models; the QML files; AI
  culling and runtime; editor, bridge and packaging), plus a full test run.
- **reproduced** = the failure was run in a throwaway script. **traced** = every step was read in
  code. **suspected** = part of the chain could not be checked here (no RAW sample, no Windows, no
  PhotoCraft build); the row says which.
- Line numbers are as of `d7b7a84` and will drift.
- Not done: the application was not driven interactively, nothing was run on Windows, no installer
  was built, and the PhotoCraft editor was not built.

## Triage levels

| Level | Meaning |
|---|---|
| **P0** | Loses or destroys the user's work, or does a destructive thing they did not ask for. |
| **P1** | Blocks a release, or a visible control that does nothing or lies. |
| **P2** | Reliability, performance on large folders or shares, security hardening. |
| **P3** | Cleanup, polish, dead code. |

Status: **fixed** (in the pass recorded at the end of this file), **open**, or **decision** (needs
the owner to choose a behaviour before it can be fixed).

## Structural shortsights

1. **Path strings are identity.** Decisions, collections, the catalog, thumbnails and edits are keyed by absolute path with four normalisations (raw, `normcase`, `casefold`, `resolve()+casefold`). Nothing survives a folder rename or drive-letter change. Root of D2, D7, D13, D16, N4, N17.
2. **Every change is a full model reset.** `PhotoModel._rebuild` always resets. Root of N1, N3, N4, N15.
3. **Three SQLite stores, three conventions,** each opening a connection per call.
4. **No policy for off-thread I/O,** although `path_policy` exists for it.
5. **Uncancellable ad-hoc threads** for folder loads, counts and listings; everything else shares the global pool.
6. **No single-instance guard.** Each file-association launch is a second app writing the same settings.
7. **Undo is a per-folder list of closures:** not persisted, not redoable, cleared on folder change.
8. **Windows-only in practice.** The hosted editor, the RAW preview helper and drive detection have no Linux path, so the AppImage has no RAW editing.
9. **Two save paths behind one Done button** (`raw_editor.py:714` and `:741`) produce different artefacts.
10. **`RECIPE_VERSION` is tested by equality in four places** with no migration hook.
11. **A system-wide low-level keyboard hook** is installed for the app's whole life (`editor_keys.py`).
12. **Rejection reasons are parsed from English prose** (`cull_real.py:71`); ranker scores are thrown away, so any slider change repeats the full ranking; People is per folder.
